## 1. 研究问题与假设

### 研究问题

> 在完全相同的底层 LLM、病例信息和知识条件下，引入道冲认知表示（IR），能否提高模型对患者**纵向状态变化**及**治疗调整**的判断能力？

这是一个 Yes / No 问题。它不回答「道冲是否完整」，只回答「道冲表示是否产生可观测的差异」。

### 假设

- **H0（零假设）**：道冲认知表示（C 组）相对通用结构化表示（B 组），在纵向状态判断上**不产生**超过预设最小意义的增益。
- **H1（备择假设）**：道冲认知表示相对通用结构化表示，产生稳定、可重复、具有预设最小意义的增益。

### 关键：真正要检验的是 C > B，不是 C > A

- 如果只做 `A（原始） vs C（道冲）`，C 赢了也证明不了道冲有效——可能只是「加了一个结构化模板」带来的增益。
- **B（通用结构组）是道冲真正的对手。** 只有当 C > B 时，才进入「道冲表示是否有特异性价值」的讨论；否则「结构化有效，道冲特异性未证明」。

## 2. 实验设计：四组

| 组别 | 输入方式 | 作用 |
|---|---|---|
| **A 原始组** | 原始纵向病例 + 普通临床提示词 | 基线：无任何结构加持 |
| **B 通用结构组** | 相同病例 + **通用时间序列模板**（症状/检查/治疗/变化/不确定性，无道冲概念） | 真正的对手：检验「结构化」本身的贡献 |
| **C 道冲组** | 相同病例 + **道冲 IR（六变量操作定义）** | 检验「道冲表示」是否在通用结构之上还有特异性贡献 |
| **D 专家框架组** | 相同病例 + 由优秀中医临床专家自行设计的动态认知框架 | 终极对照（PILOT 版可暂缓，正式版必做） |

### 关于 D 组（PILOT 版暂缓的理由）

D 组需要真实临床专家参与设计框架，且合成病例阶段「专家框架」的优势难以体现（合成病例是构造的，不是真实临床复杂度）。**D 组留给 EXP-02（真实数据）**。但在方案里预注册其位置：最终问题不是「道冲比没结构好吗」，而是「道冲比一个聪明人认真设计的非道冲动态框架好吗」。

## 3. 六变量操作化定义（第一次）

> 这六个变量不是新造的概念，而是从 `dao-chong-schema.json` 既有概念中**提取**出来、第一次降维为可测量变量的候选核心。下表给出：理论来源（schema 映射）、操作定义、允许的计算结果。

### 3.1 状态 State（$S_t$）

- **理论来源**：`dcx:flow-as-stability`（流动稳态）、`dcx:disease-as-trapped-flow`（困）。
- **操作定义**：时点 $t$ 下、能够影响后续行动的一组**可观测临床状态**，按体/用/象/道或四象编码成结构化向量。**不是**「患者现在怎么样」的解释性语言。
- **允许计算结果**：$S_t$ 为状态向量；$\Delta S = S_{t+1} - S_t$ 为变化。

### 3.2 约束 Constraint

- **理论来源**：`dcx:disease-as-trapped-flow`（六类病理模式：资本困顿/通道困阻/枢转困顿/调控失度/熏习固化/网络失协）。
- **操作定义**：阻止系统进入更优状态、且若解除可能改变迁移方向的因素。**禁止**只写「痰湿为患」这类理论标签；必须落到可观察症候群，例：「纳差 + 苔厚 + 脘痞 + 大便不畅 → 中焦运化约束」。
- **允许计算结果**：约束清单 + 每个约束的「解除中 / 仍存在 / 新增」。

### 3.3 势 Momentum / Tendency

- **理论来源**：`dcx:meta-principles`（极—化—传—转的「势」「近极」）、`dcx:six-operations`（药势）。
- **操作定义**：**不是**当前状态，而是状态**正在朝哪个方向改变**。由连续时点可观测指标的 $\Delta$ 方向构成。例：「口干↓、苔厚↓、食欲↑ → 中焦壅滞正在解除」。
- **允许计算结果**：各指标的 $\Delta$ 方向（↓/↑/→）+ 「同向收敛 / 相互矛盾 / 不足以判向」。

### 3.4 阈值 Threshold

- **理论来源**：`dcx:meta-principles`（「近极」、火候）。
- **操作定义**：某种治疗策略需要转换的**预定义条件**。例：「当邪实指标下降、而虚损指标持续存在达到某标准时，从『攻』为主切换到『扶复』为主」。
- **允许计算结果**：**到了 / 未到 / 不确定**（三值，禁止模糊）。

### 3.5 迁移 Transition

- **理论来源**：`dcx:meta-principles`（传—转）、`dcx:six-meridian`（传变）。
- **操作定义**：$S_t \rightarrow S_{t+1}$ 的有向转变，**以及哪些因素驱动了这次变化**（不能只说「病机变化」）。
- **允许计算结果**：状态向量的有向变化 + 驱动因素归因清单。

### 3.6 承载 Capacity

- **理论来源**：`dcx:ti-yong-xiang-dao`（体）、`dcx:shen-shui-xiang`（肾水象）、`dcx:xiang-shui-xiang`（相水象）、`dcx:flow-resilience`（支撑维度）。
- **操作定义**：系统的支撑 / 恢复能力。**这是六变量里最危险的一个——最容易沦为万能解释词。** 因此本变量必须回答一个硬问题：「什么可观察指标能说明承载下降？」候选指标：PS 变化、食纳、睡眠、体重、血象、重要脏器功能、治疗耐受、恢复速度。
- **允许计算结果**：承载「上升 / 稳定 / 下降」+ 依据的指标。

### 3.7 变量存废的预注册规则（第一次真正的「删」）

> **任何一个变量，若在标注阶段无法被两位独立标注者以足够一致度（κ 阈值）可靠操作化，则从模型**删除**，而不是降级为「理论性解释」。**
>
> 「承载」是最高优先级的删除候选。**删掉一个无法操作化的变量，不是道冲被削弱，而是从理论里第一次提取出了可实证的部分。**

## 4. 合成病例构造规范

### 4.1 数量与结构

- **总量**：60 例（3 个病种 × 20 例）。
- **纵向结构**：每例含 `T1 初诊（主诉/四诊/辨证/处方）→ 治疗 → T2 复诊（变化）→ 治疗调整 → T3（验证结局）`。
- **任务只给 T1、T2**，T3 作为事后验证，与标注阶段物理隔离（见 §11 前向标注）。

### 4.2 病种选择（须有纵向演变特征）

候选病种（择 3）：
1. 慢性脾胃病（如功能性消化不良的迁延与转归）
2. 肿瘤术后/放化疗后的调理（体层虚损的演变）
3. 失眠（心神/肾水/相火的动态失衡）
4. 外感病入里化热的内伤转化

### 4.3 势的多样性（防「典型好转」偏倚）

每个病种 20 例中，**必须**包含四类走向：
- 好转（势明确向上）
- 恶化（势明确向下）
- 僵持（势方向模糊、阈值未到）
- 信息不足（资料缺失，正确结论应为「不知道」）

**禁止**全部造「典型好转」——那样任何模板都能答对，实验失去区分度。

### 4.4 构造者隔离（防「为道冲量身定制」作弊）

> **合成病例的构造者，不得是 A/B/C 组提示词的撰写者，也不得是后续任何一组的评价者。** 构造者只按 §4.3 的走向要求 + 中医临床常识生成病例，不知道道冲六变量的具体操作定义。

## 5. 任务与五指标

### 5.1 给模型的任务（只给 T1、T2）

模型须回答六个问题：

1. 当前状态相较上一阶段发生了什么变化？
2. 哪些病理过程在解除？
3. 哪些约束仍然存在？
4. 当前治疗应**继续 / 减弱 / 加强 / 改变方向**？
5. 下一阶段最需要观察什么？
6. 哪些新信息一旦出现，会改变当前判断？

### 5.2 五指标（PILOT 版只保留五个，不多不少）

| # | 指标 | 检验什么 | 评价方式 |
|---|---|---|---|
| ① | 状态变化识别 | T1→T2 发生了什么有临床意义的变化 | 盲法专家标注关键变化，比对 |
| ② | 治疗调整判断 | 维持/减量/加强/换方向/暂停（**不评具体处方**） | 降维——「该不该转」比「换成哪张方」更接近道冲核心主张 |
| ③ | 下一步关键观察变量 | 对「势」的直接检验 | 模型列出的观察变量，是否命中 T3 决定转归的关键变量 |
| ④ | 反事实敏感性 | 机器是否真的「用了」这个表示 | 改一个关键变量，观察模型是否「该变则变、不该变则不变」 |
| ⑤ | 不确定性校准 | 模型知道自己不知道吗 | 信息不足的病例，正确答案是「信息不足」 |

### 5.3 指标④（反事实）的构造方式

原病例 `苔厚明显减轻、食欲恢复` vs 反事实病例 `苔厚加重、食欲继续下降`，其余全部不变。观察模型在**状态、势、转方判断**上是否随之改变。好的认知模型应「该变的时候变，不该变的时候不变」。

## 6. 主要终点与失败判据（死亡条款）

### 6.1 主要终点

> C 组相对 B 组，在**治疗调整判断（指标②）**与**状态迁移识别（指标①）**两项核心指标上，是否产生预设最小临床意义增益（$\Delta$）。

### 6.2 预注册的失败判据

在实验开始前写死，不得事后修改：

- **PILOT 级死亡条款（合成病例版）**：
  > 若 C 组相对 B 组，在两项核心指标上均未产生预设最小意义增益（$\Delta < 5\%$，或标准化效果量低于预设阈值），则「道冲认知表示相对通用结构化表示具有特异性可计算差异」这一假设**不成立**。此时不得写作「道冲略有提高」，应写「结构化表示有效，道冲特异性贡献未得到证明」。

- **示例（预注册的判读纪律）**：
  - `A=72, B=81, C=82` → 结论是「结构化有效，道冲特异性未证明」，**禁止**写「道冲略有提高」。
  - `A=72, B=81, C=88` → 才有资格进入 §8 消融实验，追问「哪几个道冲变量贡献了这 7 个百分点」。

- **正式级死亡条款（真实数据版，EXP-02 适用）**：
  > 若经过预注册的纵向临床任务、通用结构对照及消融实验后，道冲表示未表现出稳定、可重复且具有最小临床意义的增益，则**停止宣称道冲具有独立的 AI 认知架构价值**；保留其中被实验支持的变量，其余降级为理论性语言或删除。

### 6.3 结果的正反两面都要预注册

- 若「体用象道」「冲阳冲阴」「四象」等概念**没有**贡献，但「状态、约束、迁移、阈值」稳定产生增益 → **保留后者，删除前者**。留下的东西可能已经不像今天的「道冲」——这正是「成而能化，化而能再成」。
- 若六变量全部无增益 → 接受「道冲可能是一个漂亮的哲学解释系统，却不是有效的 AI 认知架构」。

## 7. 统计方法（PILOT 版）

- **样本量**：60 例（3 病种 × 20）。PILOT 阶段以**效应量 + 描述性对比**为主，不做过度拟合的显著性宣称。
- **盲法**：评价者不知道答案来自 A/B/C 哪一组（§10）。
- **一致性**：多标注者的 κ 一致性（尤其指标①的「关键变化」标注、以及六变量的操作化）。
- **预注册的 $\Delta$**：$\Delta$ 定义在实验开始前固定（建议：核心指标上 C 相对 B 的绝对增益 ≥ 5%，或 Cohen's d ≥ 0.3 作为「有意义」的候选阈值，最终值由 power 分析在数据生成前锁定）。

## 8. 消融实验（C 赢了才做）

假设 C > B 成立，**不要庆祝，马上删变量**：

- 完整模型：`S + C + M + T + Tr + Cap`
- 逐个消融：`−状态`、`−约束`、`−势`、`−阈值`、`−迁移`、`−承载`
- 观察性能变化：
  - 去掉某变量后**毫无变化** → 删；
  - 去掉某变量后**反而更好** → 更该删；
  - 若最后只剩 `状态—约束—迁移`，那不是道冲被削弱，而是**从理论中提取出了有实证贡献的最小计算内核**——这可能比 25 个概念珍贵得多。

## 9. 防作弊条款（整个实验的灵魂）

> **唯一变量，就是 representation。**

三组必须尽可能做到：

- 同一个底层模型；
- 相同病例文本；
- 相同知识库；
- 相同 temperature；
- 相近 token budget；
- 相同输出格式；
- 相同推理轮数；
- 评价者不知道答案来自哪一组。

**禁止给 C 组更多信息。** 若 C 组提示词写两千字、把推理路径全告诉模型，而 A 组只说「请分析病例」，那 C 组赢的是 prompt engineering，不是认知架构——那是自欺，必须被 §6.2 的死亡条款拦截。

## 10. 前向标注协议（防「势」的后见之明污染）

> 「势」的标注，若标注者已经看到 T3 结局，会无意识地事后合理化势的判断（知道结局好转，就把 T1→T2 里模棱两可的信号读成「势在向好」）。这系统性高估模型对「势」的把握。

**规则**：

- 指标①③（含「势」）的标注**必须前向进行**：标注者只看 T1→T2，**不被告知 T3 结局**；
- T3 仅作为「事后验证」，与标注阶段物理隔离；
- 标注完成并冻结后，才开放 T3 做验证比对。

## 附：本实验在道冲自证体系中的位置

EXP-01 是道冲从「falsifiable」走向「killable」的第一个落地：

- 过去道冲的 `falsifiable_claims` 是「逻辑上可被否证」；
- EXP-01 把它变成「意志上预先承诺：被否证就死」；
- **可被事实杀死，才是一个理论真正进入实验科学的标志。**

「道冲」这个名字在本实验中不受保护。若实验证明留下的变量已不像今天的道冲，就让它不像。因为道冲追求的从来不是「让道冲活下来」，而是「让经过检验仍然成立的东西活下来」。
